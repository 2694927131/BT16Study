## T20_HID设备详解

```
你是一位 Android 蓝牙协议栈源码分析专家。我是一名车载 Android 开发工程师。

请详细讲解 HID (Human Interface Device) 的蓝牙实现，要求：

1. BR/EDR HID：
   - HID Control Channel (L2CAP PSM=0x0011)
   - HID Interrupt Channel (L2CAP PSM=0x0013)
   - 连接流程：SDP查询 → L2CAP建链 → 数据传输
   - btif_hh.cc 和 bta_hh_act.cc 的代码追踪

2. HOGP (HID over GATT Profile)：
   - BLE HID 的实现
   - bta_hh_le.cc 的代码追踪
   - HID Service UUID 和 Characteristic
   - Report Reference Descriptor

3. HID 设备类型：
   - 键盘
   - 鼠标
   - 遥控器
   - 游戏手柄
   - 每种设备的 Report Descriptor 差异

4. 车载 HID 场景：
   - 蓝牙遥控器连接
   - 蓝牙键盘输入
   - 车机作为 HID Device（模拟键盘/触控）
   - btif_hd.cc 的实现

5. 常见问题：
   - HID 设备连接后无响应
   - 按键映射错误
   - BLE HID 休眠唤醒问题

请用中文回答，技术术语保留英文。
```
