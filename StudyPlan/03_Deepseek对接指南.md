# 学习执行指南

---

## 一、核心原则

**你只需要说一句话，AI 自动完成所有事情：读任务 → 生成内容 → 保存笔记 → 更新进度。**

不需要手动复制粘贴 Prompt，不需要手动保存笔记，不需要手动更新进度。

---

## 二、首次使用：发送初始化指令

在 Trae Chat 中打开 BT16Study 项目，发送以下指令（仅首次需要）：

```
你是我学习 Android 蓝牙 Framework 和协议栈的导师。请严格按照以下规则工作：

1. 任务来源：读取 StudyPlan/01_Deepseek任务拆解/ 下对应优先级目录中的任务清单文件，找到我指定的任务编号对应的 Prompt
2. 输出要求：按 Prompt 要求完整回答
3. 保存笔记：回答完成后，自动将内容保存为 Markdown 文件到 StudyPlan/学习笔记/ 对应目录，文件名格式：T{XX}_{任务简称}.md
4. 更新进度：保存笔记后，自动更新 StudyPlan/02_学习进度追踪.md 中对应任务的状态为 [x]，填写完成日期和关键收获
5. 源码参考：项目根目录下 Bluetooth/system/ 是 AOSP 蓝牙协议栈源码，回答时应结合源码验证

确认你已理解以上规则，然后等待我的任务指令。
```

AI 确认后，后续每次学习只需要一句话。

---

## 三、日常使用：一句话指令

| 你说的话 | AI 做的事 |
|----------|-----------|
| `执行 T01` | 读取 P0 任务清单中 T01 的 Prompt → 生成内容 → 保存笔记 → 更新进度 |
| `执行 T08` | 读取 P1 任务清单中 T08 的 Prompt → 生成内容 → 保存笔记 → 更新进度 |
| `执行 T13 到 T16` | 依次执行 T13、T14、T15、T16，每个都保存笔记和更新进度 |
| `继续学习` | 读取 02_学习进度追踪.md，找到下一个未完成任务，自动执行 |
| `继续上次` | 读取进度追踪，找到状态为 [~] 的任务，从上次中断处继续 |

---

## 四、中断恢复

Trae 会话中断后，新建会话发送：

```
你是我学习 Android 蓝牙 Framework 和协议栈的导师。
请读取 StudyPlan/02_学习进度追踪.md 确认当前学习进度，
然后找到下一个未完成的任务继续执行。
执行规则同前：读任务 Prompt → 生成内容 → 保存笔记 → 更新进度。
```

AI 会自动读取进度文件，找到你学到哪了，继续往下走。

---

## 五、补充指令

| 场景 | 你说的话 |
|------|----------|
| 某个任务没看懂，要重新学 | `重新执行 T05，讲得更详细一些` |
| 想针对某个点深入追问 | `关于 T08 中 A2DP 编解码器协商，请结合 btif_av_co.cc 源码再详细解释` |
| 想跳过某个任务 | `跳过 T22，标记为跳过` |
| 想看整体进度 | `显示当前学习进度` |
| 遇到实际工作问题 | `我遇到一个问题：[描述]，请帮我定位，参考 StudyPlan/00_学习知识图谱.md 中的相关模块` |
