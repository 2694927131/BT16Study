# T02_蓝牙开关流程详解

> 学习日期：2026-05-16
> 使用工具：Trae + Deepseek-v4-pro
> 状态：已完成

## 关键收获
1. 开启流程：App → Framework → Service → JNI → bluetooth.cc enable() → stack_manager start_up_stack_async → 16步初始化
2. 关闭流程：disable()→stack_manager shut_down_stack_async→断开Profile→释放资源→HCI_Reset→event_signal_stack_down
3. 状态机7个状态：OFF(10)/TURNING_ON(11)/ON(12)/TURNING_OFF(13)/BLE_TURNING_ON(14)/BLE_ON(15)/BLE_TURNING_OFF(16)
4. 车载 AutoOn.kt 实现蓝牙崩溃后自动重开；熄火可选完全关闭/BLE保活/低功耗三种策略
5. 定位开关卡住：看 bt_stack_manager 日志的 "finished" 行是否出现

## 详细笔记

### 一、蓝牙开启流程

**完整调用链**:
```
App: BluetoothAdapter.enable()
→ Framework: BluetoothManagerService.enable()
→ Service: AdapterService.enable() → enableNative()
→ JNI: com_android_bluetooth_btservice_AdapterService.enableNative()
→ BTIF: bluetooth.cc enable() [L462-470]
→ Stack: stack_manager.cc event_start_up_stack() [L236-294]
  → 16步初始化:
    1. btm_init()
    2. module_start_up(BTIF_CONFIG)
    3. l2c_init()
    4. sdp_init()
    5. gatt_init()
    6. SMP_Init()
    7. btm_ble_init()
    8. RFCOMM_Init()
    9. GAP_Init()
    10. startProfiles(): A2DP/AVRC/BNEP/HID/AR
    11. bta_sys_init()
    12. btif_init_ok()
    13. BTA_dm_init()
    14. bta_dm_enable()
    15. BTA_dm_on_hw_on()
    16. do_in_jni_thread(event_signal_stack_up)
```

**HCI 命令序列** (~11个):
1. HCI_Reset → 2. Read_Local_Version_Info → 3. Read_BD_ADDR
4. Read_Local_Supported_Features → 5. Read_Buffer_Size
6. Set_Event_Mask → 7. Write_Simple_Pairing_Mode
8. Write_LE_Host_Support → 9. Set_Event_Mask_Page_2
10. LE_Set_Event_Mask → 11. Read_Local_Supported_Codecs

**初始化完成通知**:
BTA_dm_on_hw_on() → future 完成
→ do_in_jni_thread(event_signal_stack_up)
→ invoke_adapter_state_changed_cb(BT_STATE_ON)
→ JNI → Java → Broadcast: STATE_ON(12)

### 二、蓝牙关闭流程

**完整调用链**:
```
App: BluetoothAdapter.disable()
→ Framework → Service → JNI
→ BTIF: bluetooth.cc disable() [L472-479]
→ Stack: event_shut_down_stack() [L297-344]
  → 15步清理:
    1. stack_is_running = false
    2. btm_ble_scanner_cleanup()
    3. btif_dm_on_disable()
    4. stopProfiles(): sock_cleanup, pan_cleanup
    5. bta_dm_disable()
    6. btif_dm_cleanup()
    7. bta_sys_disable()
    8. BTA_dm_on_hw_off()
    9. module_shut_down(BTIF_CONFIG)
    10. module_shut_down(DEVICE_IOT_CONFIG)
    11. gatt_free()
    12. sdp_free()
    13. l2c_free()
    14. btm_ble_free() → btm_free()
    15. do_in_jni_thread(event_signal_stack_down)
```

**清理顺序**: BLE扫描→Profile断开→ACL断开→模块关闭→协议栈释放→HCI_Reset→线程清理

### 三、蓝牙状态机

**7个状态**:
| 状态 | 值 | 含义 |
|------|-----|------|
| STATE_OFF | 10 | 蓝牙关闭 |
| STATE_TURNING_ON | 11 | 正在开启 |
| STATE_ON | 12 | 蓝牙已开启 |
| STATE_TURNING_OFF | 13 | 正在关闭 |
| STATE_BLE_TURNING_ON | 14 | BLE模式正在开启 |
| STATE_BLE_ON | 15 | 仅BLE模式 |
| STATE_BLE_TURNING_OFF | 16 | BLE模式正在关闭 |

**关键转换**:
- OFF→BLE_ON: enableBle() (仅需BLE的场景)
- BLE_ON→ON: enable() (升级到完整模式)
- ON→BLE_ON: disableBrEdr() (仅关闭BR/EDR保留BLE)
- TURNING_ON→OFF: 初始化失败/超时

### 四、车载特殊场景

**AutoOn.kt**: 监听蓝牙状态，意外关闭时自动定时重开
**休眠三种策略**: 完全关闭/BLE保活(用于唤醒)/低功耗Sniff Mode
**崩溃恢复**: System Server检测进程死亡→自动重启进程→重新init+enable

### 五、常见问题定位

**定位开关卡住**:
- 检查 `bt_stack_manager: finished` 日志行是否出现
- 卡在 TURNING_ON: 看HCI Snoop是否有HCI_Reset发出
- 卡在 TURNING_OFF: 看是否有未断开的连接

**关键日志行**:
```bash
adb logcat -s bt_stack_manager bt_btif bt_bta_dm bt_hci
```
