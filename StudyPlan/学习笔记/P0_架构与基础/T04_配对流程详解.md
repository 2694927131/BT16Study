# T04_配对流程详解

> 学习日期：2026-05-16 | 使用工具：Trae + Deepseek-v4-pro | 状态：已完成

## 关键收获
1. SSP 四种模式由双方 IO Capability 组合决定：JustWorks/NumericComparison/PasskeyEntry/OOB
2. bta_security 回调表注册了完整的 BTM 安全回调链（pin/link_key/auth_complete/sp/le_smp）
3. LE 配对走 SMP 三阶段：Feature Exchange → STK 生成 → Key Distribution
4. 配对信息存 bt_config.conf，重启时 btif_storage_load_bonded_devices() 恢复
5. 车载无屏场景 IO_CAP=None→JustWorks；CarPlay/HiCar 用 BLE OOB 配对

## 详细笔记

### 一、SSP 流程

**IO Capability**: BT_IO_CAP_OUT(DisplayOnly)/IO(DisplayYesNo)/IN(KeyboardOnly)/NONE(NoInputNoOutput)/KBDISP

**配对模式矩阵**: NoInputNoOutput参与→JustWorks；双方有Display+YesNo→NumericComparison；Display+Keyboard→PasskeyEntry

**createBond 调用链**:
App→Service→JNI→btif_dm_create_bond [btif_dm.cc L2774]
→pairing_cb.timeout_retries=NUM_TIMEOUT_RETRIES
→btif_dm_cb_create_bond→BTA_DmBond→bta_dm_sec_create_bond
→HCI_Create_Connection→IO_Cap_Request→SSP 认证→Set_Connection_Encryption
→Encryption_Change_Event→BTA bta_dm_authentication_complete_cback
→BTIF btif_dm_auth_cmpl_evt [L1130]
→btif_storage_add_bonded_device 存储LinkKey
→bond_state_changed(BOND_BONDED)→JNI→Java: BOND_BONDED

**安全回调注册 [bta_dm_sec.cc L59-67]**: tBTM_APPL_INFO bta_security 注册 pin/link_key/auth_complete/bond_cancel/sp/le/le_key/sirk 共8个回调

### 二、LE 配对

**Security Modes**: Mode1 Level1-4 (NoSecurity→SC+认证)

**Legacy vs SC**: Legacy用TK+AES-CMAC，SC用ECDH P-256

**SMP三阶段**: Feature Exchange→STK=s1(TK,Srand,Mrand)→LTK+IRK+CSRK分发

**LE createBond_le [btif_dm.cc L2793]**: btif_dm_create_bond_le→BTA_DmBond(LE)→SMP→bta_dm_ble_smp_cback→auth_cmpl_evt→bond_state_changed

### 三、存储与恢复

LinkKey存 /data/misc/bluedroid/bt_config.conf，重启时 btif_storage_load_bonded_devices() 恢复

### 四、取消配对 (removeBond)

断开所有Profile→btif_storage_remove_bonded_device()→BTA_DmRemoveDevice()→BTM_SecDeleteDevice()→bond_state_changed(NONE)

### 五、车载特殊场景

- 无屏: IO_CAP=None→JustWorks
- Auto-Pair: 匹配预定义设备自动createBond
- 多用户: 按User Handle隔离
- CarPlay/HiCar: BLE OOB 安全配对

### 六、常见问题定位

配对失败 → `adb logcat -s bt_bta_dm_sec bt_btif_dm bt_stack | grep -E "bond|pair|auth|key"`
兼容性问题 → interop_database.conf 添加设备修复
