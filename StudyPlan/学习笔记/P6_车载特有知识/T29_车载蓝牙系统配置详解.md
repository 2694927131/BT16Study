## 1. 蓝牙配置文件分层体系

```
Layer 1: build-time sysprop overlay  (编译时覆盖)
  sysprop/*.sysprop → 各profile默认参数
  device.mk → PRODUCT_PROPERTY_OVERRIDES

Layer 2: runtime configuration files  (运行时配置文件)
  /vendor/etc/bluetooth/bt_stack.conf   → 协议栈行为
  /vendor/etc/bluetooth/bt_did.conf     → 设备身份
  /vendor/etc/bluetooth/interop_database.conf → 兼容性清单

Layer 3: persistent storage  (持久化存储)
  /data/misc/bluedroid/bt_config.conf   → 配对信息+设备偏好
  /data/misc/bluedroid/bt_config.bak    → 备份
```

|------|------|----------|

## 3. bt_stack.conf 协议栈配置

### 3.1 完整配置项

源码：[bt_stack.conf](file:///d:/AndroidWorkspace/claudeProject/BT16Study/Bluetooth/system/conf/bt_stack.conf)

```ini
# === 安全配置 ===
# 强制Secure Connections Only (LE SC + BR/EDR SC)
SecureConnectionsOnly=true          # 车载建议: true (安全优先)

# === LE配置 ===
# LE连接参数更新开关
LeConnectionUpdate=true             # 建议: true

# EATT (Enhanced ATT) - 多ATT通道
EATT=true                           # 建议: true (提升GATT速度)

# L2CAP Enhanced Credit
L2capEnhancedCredit=true            # 建议: true

# === LE Audio ===
# LE Audio suspend支持
LeAudioSuspend=true                 # 新功能, 按需

# === 调试 ===
# PTS测试模式 (认证测试用)
PTSTestMode=false                   # 生产环境: false

# SMP失效测试 (安全测试用)
SmpFailureTestCase=false            # 生产环境: false
```

### 3.2 车载推荐配置

```ini
# 车载推荐 bt_stack.conf
SecureConnectionsOnly=true
LeConnectionUpdate=true
EATT=true
L2capEnhancedCredit=true
LeAudioSuspend=false             # 如不支持LE Audio则false
PTSTestMode=false
SmpFailureTestCase=false
```


## 4. Class of Device (CoD) 配置

### 4.1 CoD结构

```
CoD = 3字节 (24-bit):
  Bit 0-1: Format Type (0=format #1)
  Bit 2-7: Minor Device Class (设备小类)
  Bit 8-12: Major Device Class (设备大类)
  Bit 13-23: Major Service Class (支持的服务)

车载典型CoD:
  0x38041C (HandsFree + ObjectTransfer + Audio)
  
  Major Service: 0x380 → Audio + Object Transfer + ???
  Major Device: 0x04 → Audio/Video
  Minor Device: 0x1C → Car Audio

  或:
  0x300414 (Telephony + Audio)
  Major Service: 0x300 → Telephony + Audio
  Major Device: 0x04 → Audio/Video  
  Minor Device: 0x14 → Loudspeaker (车载)
```

### 4.2 CoD设置方式

**方式1：sysprop（[sysprops_module.cc](file:///d:/AndroidWorkspace/claudeProject/BT16Study/Bluetooth/system/gd/sysprops/sysprops_module.cc)）**：
```properties
bluetooth.device.class_of_device=0x38041C
```

**方式2：Vendor HAL**：
```cpp
// 通过VSC设置CoD (部分芯片需要)
send_vsc(VS_SET_COD, {0x1C, 0x04, 0x38}); // 小端序
```

**方式3：bt_did.conf 配合**：
```
bt_did.conf指定 DID信息(Device ID = vendor + product + version)
结合CoD共同标识车机身份
```

### 4.3 车载CoD推荐值

```
场景1: 标准车载蓝牙(音乐+通话):
  0x38041C → Car Audio + Audio + Telephony

场景2: 仅通话(商用车队):
  0x200414 → Telephony + Loudspeaker

场景3: 后排娱乐屏(仅音乐):
  0x2C0414 → Audio + Rendering + Capturing

场景4: 车载HID设备:
  0x0500 → HID Major (配合Subclass定义键盘/鼠标/遥控)
```

## 5. bt_config.conf 持久化配置

### 5.1 文件格式

```
路径: /data/misc/bluedroid/bt_config.conf
格式: INI风格, section = [Info], [Adapter], [Devices]

[Info]
FileVersion = 0x0102
TimeCreated = 2024-01-01 00:00:00

[Adapter]
Address = XX:XX:XX:XX:XX:XX
LE_LOCAL_KEY_IRK = XXXXXXXX...
Name = 某某车型蓝牙

[Devices]
XX:XX:XX:XX:XX:XX:XX:XX   # 手机BD_ADDR
  Name = iPhone 15
  DevClass = 0x7A020C
  DevType = 1
  Timestamp = 1704067200
  LinkKey = XXXXX
  LE_KEY_PENC = XXXXX
  LE_KEY_PID = XXXXX
  Profile = A2DP_SOURCE A2DP_SINK HFP_AG HFP_HF SDP_DB
  Service = ...
```

### 5.2 车载定制项

可以通过修改bt_config.conf持久化以下设置：

```
# 设备优先级 (越大约优先)
PRIORITY = 1000     # 1000=AUTO_CONNECT(上车自动连)
PRIORITY = 100      # 100=CONNECTABLE(手动触发)
PRIORITY = 0        # 0=DISABLED(禁用自动连接)

# Profile启用状态
A2DP_ENABLED = true
HFP_ENABLED = true
AVRCP_ENABLED = true
GATT_ENABLED = true
HID_ENABLED = false

# 编解码器偏好
A2DP_CODEC_PRIORITY_SBC = 1001
A2DP_CODEC_PRIORITY_AAC = 2001
A2DP_CODEC_PRIORITY_LDAC = 3000
```

### 5.3 重要的runtime property

```bash
# Snoop Log配置 (T23已详细说明)
persist.bluetooth.btsnooplogmode=filtered

# BQR配置
persist.bluetooth.bqr.event_mask=0x8C
persist.bluetooth.bqr.min_interval_ms=1000

# AVRCP版本 (行车状态下切换)
persist.bluetooth.avrccontrolversion=avrcp16
persist.bluetooth.avrcversion=avrcp16

# LE隐私 (随机地址, 防追踪)
bluetooth.core.gap.le.privacy.enabled=true

# 设备名称 (可动态修改)
bluetooth.device.default_name=某某车型蓝牙
```

## 6. 车载Profile开关控制

### 6.1 编译时控制

在 `device/<oem>/<model>/device.mk` 或 overlay中：

```makefile
# 启用的蓝牙Profile
PRODUCT_PROPERTY_OVERRIDES += \
    bluetooth.profile.a2dp.source.enabled=true \
    bluetooth.profile.a2dp.sink.enabled=false \
    bluetooth.profile.hfp.hf.enabled=true \
    bluetooth.profile.hid.host.enabled=true \
    bluetooth.profile.hid.device.enabled=false \
    bluetooth.profile.pan.nap.enabled=false \
    bluetooth.profile.pan.panu.enabled=true \
    bluetooth.profile.gatt.enabled=true \
    bluetooth.profile.avrcp.target.enabled=true \
    bluetooth.profile.avrcp.controller.enabled=true \
    bluetooth.profile.sap.enabled=false \
    bluetooth.profile.pbap.client.enabled=true \
    bluetooth.profile.pbap.server.enabled=false \
    bluetooth.profile.map.client.enabled=false
```

### 6.2 Feature Flag控制

```bash
# 查看当前支持的Profile
adb shell dumpsys bluetooth_manager | grep "Enabled Profiles"

# 输出示例:
# Enabled Profiles: A2DP_SOURCE HFP_AG AVRCP_TG AVRCP_CT HID_HOST PAN_PANU PBAP_CLIENT
```

### 6.3 车载标准Profile组合

**车型：标准车载娱乐（音乐+通话+配对+互联）**：

```makefile
# 必须开启
bluetooth.profile.a2dp.source.enabled=true          # 音乐播放(Source)
bluetooth.profile.hfp.hf.enabled=true               # 车载HF(接听方)
bluetooth.profile.avrcp.controller.enabled=true     # AVRCP控制(切歌/暂停)
bluetooth.profile.avrcp.target.enabled=true         # AVRCP目标(被控制)
bluetooth.profile.gatt.enabled=true                 # GATT(BLE+手机互联)
bluetooth.profile.pbap.client.enabled=true          # 电话本下载

# 可选开启
bluetooth.profile.hid.host.enabled=true             # HID遥控器
bluetooth.profile.pan.panu.enabled=true             # PAN网络共享(手机给车机上网)

# 必须关闭
bluetooth.profile.a2dp.sink.enabled=false           # 车机不做Sink
bluetooth.profile.map.client.enabled=false          # 短信用不到
```
