# v2 物料包示例：13.2 SMP 详解

> 本文件是 `doc/v2_编写规范.md` §3 物料包规范的**完整实例**。
>
> 选择 13.2 SMP 详解作为示例的原因：
> 1. SMP 是 P1 重点（安全章节），是中等模型试点首选
> 2. v1 已有基础（`doc/学习资料/13_安全与加密/13.2_SMP详解.md`），便于对比 v1 → v2 的质量提升
> 3. SMP 涉及完整的状态机 + 加密 + 协议 + 调试，能完整跑通十二段式
>
> **本物料包中的所有 `file:line` 与函数名均经过 Grep 实际验证**（验证日期 2026-05-25，AOSP 基线 android-16.0.0_r5）。
> 制作物料包的最低要求：每一条 `allowed_refs` 都必须能在仓库中实际找到。

      tSMP_STATUS SMP_Pair(const RawAddress& bd_addr, tBLE_ADDR_TYPE addr_type) {
        tSMP_CB* p_cb = &smp_cb;
        log::verbose("addr_type:0x{:02x}, bd_addr:{}, state:{}",
                     addr_type, bd_addr, p_cb->state);

        if (p_cb->state != SMP_STATE_IDLE ||
            p_cb->smp_over_br ||
            p_cb->flags & SMP_PAIR_FLAGS_WE_STARTED_DD) {
          // 已有配对进行中，拒绝并发
          return SMP_BUSY;

        smp_sm_event(p_cb, SMP_PAIR_REQ_EVT, NULL);
        return SMP_STARTED;
