# 05.3 Stack 核心导读：分层与公共组件

> 速通摘要：Stack（`system/stack/`）是**蓝牙协议本体**。22 个子目录按协议分层：**底层** `acl/`、`hcic/`；**链路** `btm/`、`l2cap/`；**中间** `rfcomm/`、`sdp/`、`smp/`；**音频** `avct/`、`avdt/`、`avrc/`、`a2dp/`；**BLE** `gatt/`、`eatt/`；**业务** `hid/`、`pan/`、`bnep/`、`gap/`、`srvc/`、`rnr/`、`connection_manager/`、`arbiter/`、`ais/`。本节给出全局地图与导读顺序。

## 5. Stack 公共组件

### 5.1 BTU（Bluetooth Upper） / btu_task
**注意**：本仓 Android 16 已把 btu_task 大部分功能整合到 GD 与 main_thread；但很多旧称还在源码里出现。
- 任务调度：所有 Stack 业务跑在 "main_thread"（同 BTA）。
- 定时器：`alarm` 框架（`system/osi/alarm.cc`）。

### 5.2 ACL（链路）
- `system/stack/acl/acl.cc` / `acl.h` / `acl_api.cc` / `acl_interface.cc` / `btm_acl.cc`：管理 Classic + LE ACL 链路。
- `ble_acl.cc`：LE ACL 特殊处理（参数更新、PHY 切换等）。
- `btm_pm.cc`：Power Mode（Sniff/Active）。

### 5.3 BTM（Base Manager）
最大且最核心。子文件：
- `btm_inq.cc` — Inquiry（Classic 扫描）
- `btm_ble_*.cc` — BLE 各类（地址、广告、扫描、隐私、配对）
- `btm_sec.cc` — Classic 安全（SSP）
- `btm_sco.cc` — SCO
- `btm_devctl.cc` — 设备控制
- `btm_dev.cc` — 设备记录

> BTM 既是"业务接口"（被 BTA 调），也包含一些底层逻辑（与 HCI 直接对接）。读 BTM 是理解 Stack 的入口。

## 6. Stack 与 BTA 边界

每个 Profile，BTA → Stack 的接口通常体现在一组 `<Stack>_*` 函数：

| BTA Profile | Stack 接口 |
|-------------|-----------|
| BTA_DmXxx | `BTM_*` (Inquiry / Bond / SCO) |
| BTA_Av | `AVDT_*` (媒体) + `AVRC_*` (控制) |
| BTA_Hf*  | `RFCOMM_*` + AT 解析在 BTA |
| BTA_Gattc | `GATT_*` |
| BTA_HhEnable | `HID_HostInit` |

## 8. 读源码建议顺序

如果你目标是"读懂 Stack 全貌"，按下面顺序：

1. `include/`（看公共类型 `tBT_TRANSPORT`、`RawAddress`、`tBTM_STATUS` 等）。
2. `btm/btm_devctl.cc`（栈初始化时的 BTM 启动）。
3. `acl/btm_acl.cc`（ACL 状态机）。
4. `l2cap/l2c_main.cc`（L2CAP 主入口）。
5. 按业务挑：A2DP → `avdt/avdt_msg.cc`；GATT → `gatt/gatt_main.cc`；HFP → `rfcomm/`。

## 11. FAQ

**Q1：Stack 和 GD 是什么关系？**
A：GD（`system/gd/`）是新栈基础设施（HCI / HAL / Storage / Metrics）；Stack 是传统的协议实现。两者通过 `system/main/shim/` 互通。详 05.4。

**Q2：为什么 BTM 这么大？**
A：历史上 BTM 不仅是 Base Manager，还包含 Inquiry/Page/SCO/SSP/SMP 触发等。新代码逐步拆出去。

**Q3：能不能不用 BTA 直接调 Stack？**
A：技术可以，但需自己维护状态。BTA 的好处是"状态机一致性"。

**Q4：Stack 之上能直接用吗？**
A：不直接 —— App 进程对 Stack 没访问权限（蓝牙 App 进程独占）。系统库 `libbluetooth.so` 不导出 Stack API 给外部。

**Q5：协议层缺少哪个？**
A：本仓基本完整。LE Audio 的部分协议（ISO/CIS）在 GD 内；UWB 不属于蓝牙。
