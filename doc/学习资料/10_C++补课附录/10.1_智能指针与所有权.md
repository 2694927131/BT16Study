# 10.1 智能指针与所有权（含 Java 对照）

> 速通摘要：C++ 没有 Java 那种"GC 一切引用"的奢侈。**智能指针**是给"对象的生命周期"加了所有权语义：`unique_ptr` = 唯一拥有；`shared_ptr` = 共享拥有（引用计数）；`weak_ptr` = 弱引用避免循环。蓝牙 Native 代码大量用智能指针——例如 BTIF 投递任务 `do_in_main_thread(base::BindOnce(&fn, std::unique_ptr<Msg>(p)))`。

---

## 3. 三种智能指针速对照

| C++ | 语义 | Java 类比 |
|-----|------|---------|
| `std::unique_ptr<T>` | 唯一所有权；不可拷贝，可 `std::move` | "局部变量持有，作用域结束销毁"（≈ Java 普通局部 + try-with-resources） |
| `std::shared_ptr<T>` | 共享所有权；引用计数 | Java 普通强引用 |
| `std::weak_ptr<T>` | 弱引用，不增加计数 | `java.lang.ref.WeakReference` |

**关键差别**：C++ "所有权"是**编译期 + 运行期**双重约束；Java 只在运行期由 GC 决定。

---

## 4. `unique_ptr`：唯一所有权

```cpp
// 基本用法
std::unique_ptr<int> p = std::make_unique<int>(42);
std::cout << *p;     // 42

// 不可拷贝
std::unique_ptr<int> q = p;   // ❌ 编译错

// 可 move
std::unique_ptr<int> r = std::move(p);   // p 失效
```

蓝牙真实用例（思路图，类似 `bta_dm_device_search.cc`）：
```cpp
void bta_dm_post_event(tBTA_DM_DEV_SEARCH_EVT event,
                      std::unique_ptr<tBTA_DM_MSG> msg) {
    do_in_main_thread(base::BindOnce(&bta_dm_search_sm_execute,
                                     event, std::move(msg)));
}
```

`unique_ptr` 表达"消息所有权从调用者转给执行者"，传过去之后调用者就**不应该再访问**。

**Java 类比**：
```java
// Java 没有"唯一所有权"，但能用借鉴模式：
try (Message msg = new Message()) {
    handler.post(() -> consume(msg));  // 但 Java 不能阻止 caller 之后再用 msg
}
```

## 5. `shared_ptr`：共享所有权

```cpp
std::shared_ptr<Service> svc = std::make_shared<Service>();
std::shared_ptr<Service> svc2 = svc;  // 引用计数 +1，两人共享
// svc 与 svc2 都失去引用时，Service 销毁
```

蓝牙真实用例（GD `Module` 框架）：
```cpp
std::shared_ptr<HciLayer> hci_ = nullptr;
auto hci = std::make_shared<HciLayer>();
hci->Start();
shim.RegisterModule(hci);   // shim 持有
```

**Java 类比**：
```java
// shared_ptr ≈ Java 普通强引用
Service svc = new Service();
List<Service> registry = ...;
registry.add(svc);    // registry 也持有 → svc 在两人都不引用时 GC
```

## 6. `weak_ptr`：弱引用

```cpp
std::shared_ptr<A> a = std::make_shared<A>();
std::weak_ptr<A> wa = a;
if (auto sp = wa.lock()) {   // 取一次强引用，可能失败
    sp->do_something();
} else {
    // a 已销毁
}
```

蓝牙用例（典型：避免回调里循环引用）：
```cpp
std::weak_ptr<SessionManager> weak_self = shared_from_this();
event_dispatcher.subscribe([weak_self](Event e) {
    if (auto self = weak_self.lock()) self->onEvent(e);
});
```

**Java 类比**：`new WeakReference<>(target)` + `target.get()`，同一思路。

## 7. RAII 与析构

智能指针靠 **RAII**（Resource Acquisition Is Initialization）— 对象出作用域时自动析构。Java 类比 = `try-with-resources` + `AutoCloseable.close()`。

```cpp
{
    std::unique_ptr<File> f = std::make_unique<File>("/path");
    f->write(data);
}   // f 销毁 → File 析构 → 自动关闭
```

```java
// Java 等价
try (File f = new File("/path")) {
    f.write(data);
}   // f.close() 自动调
```

## 8. 常见陷阱

### 陷阱 1：循环引用
```cpp
class A { std::shared_ptr<B> b; };
class B { std::shared_ptr<A> a; };   // ❌ A 持有 B，B 持有 A → 永不释放
```
解：把其中一边改 `weak_ptr`。

### 陷阱 2：混合裸指针
```cpp
A* raw = new A();
std::unique_ptr<A> p1(raw);
std::unique_ptr<A> p2(raw);   // ❌ 双重释放，crash
```
解：始终用 `make_unique` / `make_shared`。

### 陷阱 3：`unique_ptr` 传给 callback 后被消费
```cpp
auto p = std::make_unique<Msg>();
callback(std::move(p));
p->use();   // ❌ p 已经 move 走了，访问 nullptr
```
解：move 后不要再访问。

## 9. 蓝牙代码常见模式

| 模式 | 用法 |
|------|------|
| 投递消息到 main_thread | `do_in_main_thread(BindOnce(fn, std::unique_ptr<Msg>(p)))` |
| 注册 callback | `weak_ptr<Self>` 防循环引用 |
| 全局 Service 句柄 | `std::shared_ptr<HciLayer>` 由 GD 模块系统持有 |
| 临时缓冲 | `std::unique_ptr<uint8_t[]>` 替代 `new uint8_t[N]` |

## 12. 本节小结（速记卡）

```
智能指针三种：
  unique_ptr   唯一所有权（不可拷贝、可 move） ≈ Java try-with-resources 局部
  shared_ptr   共享所有权（引用计数） ≈ Java 强引用
  weak_ptr     弱引用（不增计数） ≈ WeakReference

RAII：对象出作用域自动析构 ≈ Java try-with-resources + AutoCloseable

陷阱：
  循环引用 → weak_ptr 打破
  混合裸指针 → 用 make_unique / make_shared
  move 之后访问 → 不要再用源指针

蓝牙常见用法：
  do_in_main_thread(BindOnce(fn, std::unique_ptr<Msg>))
  GD Module: std::shared_ptr<Module>
  callback 内：weak_ptr<Self>
```
