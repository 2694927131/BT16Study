# 10.3 Lambda / `std::function` / 回调（含 Java 对照）

> 速通摘要：C++ Lambda + `std::function` = "**第一类函数对象**"。蓝牙 Native 大量用 `base::BindOnce(&fn, arg)` 把"一段逻辑 + 参数"打包成 Closure，再投递到 main_thread 异步执行——这跟 Java `Runnable` + `Handler.post(...)` 同一思路。

## 3. C++ Lambda 基础

```cpp
auto greet = [](const std::string& name) {
    std::cout << "Hello, " << name;
};
greet("Bluetooth");
```

### Capture（捕获）

| Capture | 写法 | 行为 |
|---------|------|------|
| 值捕获 | `[x]` | 复制 x 进 lambda |
| 引用捕获 | `[&x]` | 引用 x（生命周期要自管） |
| 全部值 | `[=]` | 当前作用域所有自动变量按值 |
| 全部引用 | `[&]` | 同上按引用 |
| 移动捕获 | `[p = std::move(unique_p)]` | C++14 起，move 进 lambda |
| `this` | `[this]` 或 `[*this]`（C++17 复制对象） | 在成员函数 lambda 内 |

```cpp
auto p = std::make_unique<Msg>();
auto cb = [p = std::move(p)]() { p->use(); };
// 现在 p 已 move 进 lambda，外面访问失效
```

## 4. `std::function`：可调用对象的统一包装

```cpp
std::function<void(int)> f;
f = [](int x){ std::cout << x; };
f(42);

f = some_free_function;        // 函数指针也行
f = [obj](int x) { obj.go(x); };  // 任意可调用都行
```

**类比 Java**：`Consumer<Integer>`、`Function<T,R>`、`Runnable` 这些 functional interface。

---

## 5. `std::bind` 与 `base::BindOnce`

```cpp
// C++ std::bind
std::function<void()> f = std::bind(&Service::start, &service);
f();   // 调 service.start()

// Chrome/Android base::BindOnce（蓝牙代码常用）
base::OnceCallback<void(int)> cb = base::BindOnce(&MyFn, std::move(arg));
std::move(cb).Run(42);
```

蓝牙真实用例（思路图）：
```cpp
// system/btif/src/btif_dm.cc
do_in_main_thread(base::BindOnce(&bta_dm_search_sm_execute,
                                 BTA_DM_API_SEARCH_EVT,
                                 std::move(msg)));
```

含义：把"调用 `bta_dm_search_sm_execute(EVT, msg)`"打包成 OnceCallback，投递到 main_thread 后再调。

## 6. C++ vs Java 翻译表

| C++ | Java |
|-----|------|
| `auto f = [](int x){ return x*2; };` | `Function<Integer,Integer> f = x -> x*2;` |
| `std::function<void()> r = [](){...};` | `Runnable r = () -> {...};` |
| `std::function<void(int)> c = [](int x){...};` | `Consumer<Integer> c = x -> {...};` |
| `std::function<int(int)> u = [](int x){return x+1;};` | `IntUnaryOperator u = x -> x+1;` |
| `base::BindOnce(&fn, arg)` | `() -> fn(arg)` 或 `Runnable` |
| `lambda by value [=]` | Java lambda 自动按值捕获 final/effectively-final |
| `lambda by reference [&]` | Java 没有等价（强制 effectively-final） |
| `lambda by move [p=std::move(p)]` | Java 没有等价 |

## 7. 蓝牙回调模式

### 7.1 BTIF → JNI 回调表
```cpp
// 04.4 节看过
static bt_callbacks_t sBluetoothCallbacks = {
    sizeof(sBluetoothCallbacks),
    adapter_state_change_callback,
    // ……
};
```
这是 "C 风格函数指针表"，不是 Lambda。

### 7.2 GD Module 模型（C++ 类回调）
```cpp
class HciLayer : public Module {
public:
    void RegisterEventHandler(EventCode code, common::ContextualCallback<void(EventView)> cb);
};
```
`ContextualCallback` 类似 `std::function`，但还绑定了"在哪个 Handler 上跑"。

### 7.3 Java App 端回调
```java
gatt.connectGatt(ctx, false, new BluetoothGattCallback() {
    @Override public void onServicesDiscovered(BluetoothGatt g, int status) { ... }
});
```
等价 C++ 的"接口实现"或"lambda 注册"。

## 8. Capture 陷阱

### 陷阱 1：引用捕获后变量销毁
```cpp
auto* foo = new Foo();
auto cb = [&foo]() { foo->bar(); };
delete foo;        // cb 持有的引用 dangling
cb();              // ❌ UB
```

### 陷阱 2：`[=]` 捕获 `this`（C++17 前）
```cpp
class A {
    void start() {
        post([=]() { this->doStuff(); });   // [=] 实际只复制 this 指针
    }
};
// 若 A 已销毁，this->doStuff() crash
```
C++17 起可用 `[*this]` 显式复制对象。

### 陷阱 3：`std::function` 内部分配
`std::function` 用类型擦除，可能分配堆内存（小对象优化外）。性能敏感场景用 templated callback。

## 11. 本节小结（速记卡）

```
C++ Lambda：[]() {} 形式，capture 控制访问外部
三种 capture：by-value [x] / by-reference [&x] / by-move [p=std::move(p)]
std::function<Signature> = 类型擦除的可调用对象 ≈ Java functional interface
base::BindOnce(&fn, args...) = 蓝牙投递任务标准模式
关键陷阱：引用捕获生命周期 / [=]+this / std::function 堆分配
Java 类比：
  Runnable / Consumer<T> / Function<T,R> ≈ std::function
  () -> {...} ≈ [](){}
注意：Java 自动按值捕获 final 变量；C++ 必须显式
```
