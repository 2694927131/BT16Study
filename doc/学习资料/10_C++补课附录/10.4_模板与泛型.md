# 10.4 模板与泛型（含 Java 对照）

> 速通摘要：C++ 模板 `template<typename T>` ≈ Java 泛型，但**本质不同**：C++ 模板**编译期实例化**（每个 T 各生成一份代码）；Java 泛型**运行期擦除**（只有一份代码，T 被擦成 Object）。蓝牙 Native 用模板较少，但 GD 框架内大量用（如 `PacketView<T>`、`HciCommandBuilder<T>`）。

## 3. C++ 函数模板

```cpp
template<typename T>
T max_of(T a, T b) { return (a > b) ? a : b; }

int x = max_of(1, 2);            // T = int
double y = max_of(1.0, 2.0);     // T = double
```

编译期为每个 T 生成对应代码 —— 二进制里实际是多个函数。

Java 等价：
```java
public static <T extends Comparable<T>> T maxOf(T a, T b) {
    return a.compareTo(b) > 0 ? a : b;
}
```
区别：Java 单份代码 + 运行期 `compareTo` 调用；C++ 直接调编译期决定的 `operator>`。

## 4. C++ 类模板

```cpp
template<typename T>
class Stack {
private:
    std::vector<T> data;
public:
    void push(T v) { data.push_back(v); }
    T pop() { T v = data.back(); data.pop_back(); return v; }
};

Stack<int> ints;
Stack<std::string> strs;
```

Java 等价：
```java
class Stack<T> {
    private List<T> data = new ArrayList<>();
    void push(T v) { data.add(v); }
    T pop() { return data.remove(data.size()-1); }
}
```

## 5. 三大根本差别

| 维度 | C++ 模板 | Java 泛型 |
|------|---------|---------|
| **何时生效** | 编译期实例化 | 编译期擦除，运行期统一 |
| **二进制膨胀** | 每个类型一份 | 单份 |
| **能用基本类型？** | 是（`Stack<int>` 合法） | 否（必须装箱 `Stack<Integer>`） |
| **能限制类型？** | SFINAE / concept (C++20) | `<T extends X>` |
| **编译错信息** | 又长又难懂 | 相对友好 |
| **运行时反射** | 几乎不可 | 可 |

## 6. SFINAE 与 concept（C++20）

```cpp
// C++17 SFINAE
template<typename T,
         typename = std::enable_if_t<std::is_integral_v<T>>>
T plus_one(T x) { return x + 1; }
// 仅当 T 是整数类型才能用

// C++20 concept
template<std::integral T>
T plus_one(T x) { return x + 1; }
```

Java 等价：`<T extends Number>`（但限制能力弱得多）。

### 7.2 ScopedLocalRef（JNI 端）
```cpp
template<typename T>
class ScopedLocalRef {
private:
    JNIEnv* env_;
    T ref_;
public:
    ScopedLocalRef(JNIEnv* env, T ref) : env_(env), ref_(ref) {}
    ~ScopedLocalRef() { if (ref_) env_->DeleteLocalRef(ref_); }
    T get() const { return ref_; }
};
// 用法
ScopedLocalRef<jbyteArray> arr(env, env->NewByteArray(N));
```

## 8. `auto` 与 `decltype`

```cpp
auto x = 1 + 2;                  // x 是 int
auto& y = some_function();       // y 是引用
decltype(x) z = x;               // z 与 x 同类型
auto lambda = [](int a) { return a + 1; };  // 自动推 lambda 类型
```

Java 类比：`var x = 1 + 2;`（Java 10+ var）。

## 12. FAQ

**Q1：C++ 模板能不能像 Java 泛型那样限制类型？**
A：能（SFINAE / concept），且更强（可对返回类型、操作符存在性约束）。

**Q2：模板报错能不能更友好？**
A：用 concept（C++20）大幅改善。GCC/Clang 都有 nice-error mode。

**Q3：什么时候用模板，什么时候用虚函数？**
A：模板适合"类型已知，不要运行时多态" → 性能好；虚函数适合"运行时多态" → 灵活。蓝牙栈两者都用。

**Q4：模板能调试吗？**
A：和普通 C++ 函数一样，调试器能进入实例化的版本（变量名带 `<int>` 后缀）。

**Q5：Java 泛型方法 vs 类，C++ 一样吗？**
A：C++ 函数模板与类模板独立存在；可分别使用。

## 14. 本节小结（速记卡）

```
C++ 模板：编译期实例化，每个 T 一份代码
Java 泛型：运行期类型擦除，单份代码
区别：基本类型支持 / 二进制大小 / 错信息友好度 / 反射可用性

写法：
  template<typename T> T fn(T a, T b);
  template<typename T> class C { ... };

限制类型：C++17 SFINAE / C++20 concept；Java <T extends X>

蓝牙用法：
  GD PDL 生成 PacketView<T>
  ScopedLocalRef<jbyteArray>
  STL 容器（vector / unordered_map / 等）

auto / decltype：类型推导（≈ Java var）
```
