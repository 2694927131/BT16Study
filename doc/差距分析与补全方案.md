## 3. 差距清单（按重要性分三档）

### 3.1 必加（5 章，约 22 节）

#### 12 LE Audio 全景  [严重缺口]
**为什么必加**：Android 16 的核心演进就是 LE Audio。本仓 `system/bta/le_audio/`、`android/app/src/.../le_audio/`、`android/app/src/.../bass_client/`、`android/app/src/.../vc/`、`android/app/src/.../mcp/`、`android/app/src/.../tbs/`、`android/app/src/.../hap/`、`android/app/src/.../csip/` 都是 LE Audio 相关，现有文档**几乎零覆盖**。
**章节**：
- 12.1 LE Audio 全景（Unicast / Broadcast / Auracast / TMAP / HAP / 与 Classic 比较）
- 12.2 LC3 编解码
- 12.3 CIS / BIS（Isochronous Streams）/ ISO Channel
- 12.4 CSIP / VCP / MCP / TBS 四件套
- 12.5 ASHA 助听器（兼容 LE Audio HAP 前的方案）
- 12.6 LE Audio 在车机上的接入与故障排查

#### 13 安全与加密专题  [深度缺口]
**为什么必加**：现有 03.3 仅讲"配对入口"，对 SSP / SMP / Privacy / Link Key 的协议机制点到为止。出 bug 时（"为什么 iPhone 配不上"、"为什么解绑后又自动配回来"、"RPA 怎么解析"）现有资料不足以定位。
**章节**：
- 13.1 SSP 详解（Numeric Comparison / Passkey Entry / Just Works / OOB；IO Capability 协商）
- 13.2 SMP 详解（LE Legacy / LE Secure Connections；ECDH；passkey 显示与输入）
- 13.3 LE Privacy（RPA / IRK / Identity Address；地址解析过程）
- 13.4 Link Key 类型、持久化、Cross-Transport Key Derivation
- 13.5 蓝牙 5.3+ 安全增强（Encryption Key Size、Address Resolution、Pairing Failure 码）

#### 14 OBEX 系 Profile（PBAP / MAP / SAP / OPP）  [覆盖缺失]
**为什么必加**：车机 HMI 显示电话簿、短信、来电 ID 这些全靠这一系列 Profile。现有资料完全没讲 OBEX 层。本仓 `android/app/src/.../pbap/`、`pbapclient/`、`map/`、`mapclient/`、`sap/`、`opp/` 都没出现在任何章。
**章节**：
- 14.1 OBEX 协议族总览（在 RFCOMM 之上的对象交换）
- 14.2 PBAP（车机电话簿同步：PCE/PSE、vCard、文件夹结构）
- 14.3 MAP（车机短信 + 通知：MAS/MNS、消息上报）
- 14.4 SAP（SIM Access，欧洲车常用）+ OPP（文件传输）

#### 15 HID / PAN / 其他 Profile  [完整性缺口]
**为什么必加**：方向盘按键映射到蓝牙 HID 是车机定制场景；PAN 用于蓝牙网络共享；这些都有 AOSP 实现但现有资料零覆盖。
**章节**：
- 15.1 HID Host（车机做 Host）+ HID Device（车机做 Device，少见但用于 Aux 显示）
- 15.2 PAN / BNEP（蓝牙网络共享）
- 15.3 其它 Profile 速览（DIS 设备信息、Battery、IAS 立即警报、HoGP 等）

#### 16 音频路由与 Audio HAL 深入  [车机最大坑]
**为什么必加**：现有 06.5 / 07.5 提到 `dumpsys audio` 但没讲清"路由是怎么从 Java 一路决定到芯片"。这是车机最大的 bug 集中区——MIC 切换、回声、Audio Focus、STREAM 类型选错等。
**章节**：
- 16.1 AudioFlinger / AudioPolicyManager / AudioManager 三件套与蓝牙的接合
- 16.2 A2DP / HFP / LE Audio 三种 Offload 路径（system/audio_hal_interface 深入）
- 16.3 STREAM_MUSIC / STREAM_BLUETOOTH_SCO / STREAM_VOICE_CALL 类型与音量
- 16.4 音频延迟（A2DP buffer / HFP SCO / LE Audio Presentation Delay）

**为什么推荐**：00.1 / 02.4 / 03.1 提到这一层但没讲 Kotlin 实现。这是 Mainline 模块的关键，且车厂经常需要在这层加策略钩子。
**章节**：
- 18.1 BluetoothService.kt / AdapterState.kt 拆解
- 18.2 AutoOn / 飞行模式 / 卫星模式 / DPM 限制联动
- 18.3 蓝牙 App 进程生命周期管理（拉起 / 监视 / 崩溃重启）

#### 19 性能、功耗、Metrics、BQR
**为什么推荐**：车机 QA 的高频指标，但现有资料无独立章。
**章节**：
- 19.1 BQR（Bluetooth Quality Report）协议与上报路径
- 19.2 Statsd 蓝牙指标 + dumpsys metrics
- 19.3 功耗分析（power_telemetry / sysprop / 控制器低功耗模式）
