# Android 16 车载蓝牙学习资料开发计划

日期：2026-05-16  
目标：基于当前源码生成可持续扩展的学习资料、源码索引与调试手册。

## 1. 工作原则

- 先索引源码，再写讲解；所有关键调用链必须能回到真实路径。
- 先做总览和主链路，再补 Profile 深水区。
- 每章都采用“前置知识 -> 场景 -> 调用链 -> 源码片段 -> 图 -> 调试任务”的统一结构。
- 外部仓库没有的内容只讲边界和交互点，不虚构实现。

## 3. 章节拆分

1. `00-总览.md`：仓库结构、Android 蓝牙分层、阅读路线。
2. `02-基础功能链路.md`：开关、扫描、配对、连接、取消配对。
3. `03-JNI桥接与回调.md`：native 方法注册、线程切换、回调到 Java。
4. `04-Native协议栈入门.md`：BTIF、BTA、Stack、GD、HCI、L2CAP、SDP、RFCOMM。
5. `05-蓝牙音乐A2DP_AVRCP.md`：连接、播放控制、绝对音量、音频流。
6. `06-蓝牙电话HFP.md`：HFP AG/Client、SCO、通话状态。
7. `07-BLE_GATT与AIoT.md`：车载外设交互与 OTA 思路。
8. `08-手机互联.md`：互联方案中蓝牙承担的配对、通道、认证辅助角色。
9. `09-C++源码阅读补课.md`：蓝牙源码中真实出现的 C++ 模式。
10. `10-故障排查手册.md`：按问题现象组织定位路线。
11. `98-术语表与阅读路线.md`：术语表、阅读路线、章节验收清单。
12. `99-开发调试准备.md`：编译、烧录、日志、snoop、dumpsys、常用 adb，按用户要求放在最后处理。
