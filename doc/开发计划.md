## 5. 风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 源码量巨大，无法穷尽 | 章节内容可能挂一漏万 | 采用"导读 + 关键路径 + 索引"而非全文翻译，源码索引文档补强 |
| 外部依赖（system_server、HAL）不在仓内 | 调用链断裂 | 显式标注"外部依赖"并给 AOSP 官方路径 |
| flag/aconfig 控制行为差异 | 文档结论可能偏向某条分支 | 凡涉及 flag 必须列出 flag 名与默认值，多分支并存时拆开讲 |
| Android 16 与 15/14 API 差异 | 旧资料可能误导 | 文中所有 API 默认基于本仓 Android 16 实现，跨版本差异单列小节 |
