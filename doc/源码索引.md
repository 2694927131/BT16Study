# Android 16 Bluetooth 源码索引

日期：2026-05-16  
说明：本索引用于支撑学习资料写作。路径均来自当前仓库。

## 1. Framework API 层

| 功能 | 路径 | 关键类/方法 | 说明 |
| --- | --- | --- | --- |
| 蓝牙总入口 | `framework/java/android/bluetooth/BluetoothAdapter.java` | `enable()`、`disable()`、`startDiscovery()`、`getProfileProxy()` | App/Settings 常用 API 入口 |
| 远端设备 | `framework/java/android/bluetooth/BluetoothDevice.java` | `createBond()`、`connect()`、`disconnect()`、`connectGatt()` | 配对、连接、BLE GATT 入口 |
| Profile 常量 | `framework/java/android/bluetooth/BluetoothProfile.java` | Profile ID、连接状态 | A2DP/HFP/GATT 等 Profile 抽象 |

## 2. 蓝牙服务层

| 功能 | 路径 | 关键类/方法 | 说明 |
| --- | --- | --- | --- |
| 栈总服务 | `android/app/src/com/android/bluetooth/btservice/AdapterService.java` | `enableNative()`、`startDiscovery()`、`createBond()`、`connectAllEnabledProfiles()` | Framework API 进入蓝牙 APK/service 后的核心调度 |
| 状态机 | `android/app/src/com/android/bluetooth/btservice/AdapterState.java` | `StateMachine` 子类 | 管理 Adapter 开关状态 |
| 配对状态机 | `android/app/src/com/android/bluetooth/btservice/BondStateMachine.java` | `createBond()` 相关消息 | 配对流程核心 |
| 远端设备缓存 | `android/app/src/com/android/bluetooth/btservice/RemoteDevices.java` | `DeviceProperties` | 设备属性、名称、绑定状态 |
| 活跃设备 | `android/app/src/com/android/bluetooth/btservice/ActiveDeviceManager.java` | A2DP/HFP/LE Audio active device | 车机多音频设备切换重点 |

## 3. Profile Service 层

| 场景 | 路径 | 关键类/方法 |
| --- | --- | --- |
| A2DP Source | `android/app/src/com/android/bluetooth/a2dp/A2dpService.java` | `connect()`、`disconnect()`、`setActiveDevice()` |

| A2DP Sink | `android/app/src/com/android/bluetooth/a2dpsink/A2dpSinkService.java` | 车机作为音频接收端 |

| AVRCP Controller | `android/app/src/com/android/bluetooth/avrcpcontroller/AvrcpControllerService.java` | 控制远端播放器 |
| HFP AG | `android/app/src/com/android/bluetooth/hfp/HeadsetService.java` | 车机/设备免提相关能力 |
| HFP Client | `android/app/src/com/android/bluetooth/hfpclient/HeadsetClientService.java` | 车机连接手机电话最常见入口 |
| GATT | `android/app/src/com/android/bluetooth/gatt/GattService.java` | `clientConnect()`、`discoverServices()`、读写回调 |
| BLE Scan | `android/app/src/com/android/bluetooth/le_scan/ScanManager.java` | 扫描调度 |
