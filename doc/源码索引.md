## 10. 重点关注的"七处入口"

读者首次进入仓库建议从以下七处入手（章节里会展开）：
1. `framework/java/android/bluetooth/BluetoothAdapter.java` — 你写 App 的入口。
2. `android/app/src/com/android/bluetooth/btservice/AdapterService.java` — 蓝牙 App 主进程的中枢。
3. `android/app/src/com/android/bluetooth/btservice/AdapterNativeInterface.java` — Java 走向 Native 的钉子。
4. `android/app/jni/com_android_bluetooth_btservice_AdapterService.cpp` — JNI 落点。
5. `system/btif/src/btif_dm.cc`（待验证）— 设备管理入栈点。
6. `system/bta/dm/` — 设备管理状态机。
7. `system/stack/btm/` — Inquiry/Bond/SCO 的底层实现。
