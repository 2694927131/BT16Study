# 需求文档：Android 16 车载蓝牙 Framework 与协议栈学习资料生成

版本：v1.0  
适用源码：当前工作目录下的 Android 16 Bluetooth 模块源码

## 1. 目标与边界

本任务目标是生成一套面向车载 Android 开发工程师的源码学习资料，帮助读者从“会 Android 应用开发、C++ 仅入门、蓝牙协议零基础”的状态，逐步具备阅读、修改、调试 Android 蓝牙 Framework 与 Native 协议栈的能力。

本资料以当前仓库源码为唯一事实基础。文档中涉及类名、函数名、路径、调用链时，必须优先引用真实源码；无法在当前仓库确认的外部组件，例如 Settings App、system_server 中完整 BluetoothManagerService 实现、厂商车机互联实现等，必须明确标注为“外部依赖/推断场景”，不能伪造源码路径。

## 2. 源码范围

当前仓库是 Android Bluetooth 模块源码，核心目录如下：

- `framework/java/android/bluetooth`：公开/系统蓝牙 API，例如 `BluetoothAdapter`、`BluetoothDevice`、`BluetoothProfile`。
- `android/app/src/com/android/bluetooth`：蓝牙 App 与各 Profile Service，例如 `AdapterService`、`A2dpService`、`HeadsetClientService`、`GattService`。
- `android/app/jni`：Java/Kotlin 到 Native 栈的 JNI 桥接。
- `system/btif`：BTIF 适配层，承接 JNI/Profile 调用并转入 BTA/Stack。
- `system/bta`：Profile 与设备管理的中间层状态机。
- `system/stack`：Classic/BLE 协议栈核心实现，例如 HCI、L2CAP、SDP、RFCOMM、GATT、A2DP。
- `system/gd`：GD 模块化蓝牙栈实现。
- `service/src`：系统服务相关 Kotlin 代码。

## 3. 输出目标

### 3.1 主学习资料

生成结构化 Markdown 教材，建议文件位于 `doc/学习资料/`，按主题拆分，至少包含：

1. 总览：Android 蓝牙分层架构、核心目录、关键模块职责。
2. 开发与调试准备：编译、刷机、日志、dumpsys、snoop/HCI log、常用 adb 命令。
3. Framework API 导读：`BluetoothAdapter`、`BluetoothDevice`、`BluetoothProfile`。
4. 蓝牙开关、扫描、配对、连接、取消配对流程。
5. JNI 桥接机制：native 方法注册、Java 调 Native、Native 回调 Java。
6. Native 栈基础：BTIF、BTA、Stack、GD、HCI、L2CAP、SDP、RFCOMM、SCO。
7. A2DP/AVRCP：蓝牙音乐连接、播放控制、绝对音量、音频路由排查。
8. HFP/HFP Client：蓝牙电话连接、通话状态同步、SCO 音频排查。
9. BLE/GATT：扫描、连接、服务发现、读写、通知、车载 AIoT 外设案例。
10. 车机互联专题：HiCar、CarLink、CarPlay 中蓝牙的典型角色与源码可定位点。
11. C++ 补课附录：智能指针、锁、回调、lambda、状态机、消息队列、线程模型。
12. 故障排查手册：按“现象 -> 日志 -> 源码入口 -> 可能原因 -> 验证方式”组织。

### 3.2 配套文档

- `doc/开发计划.md`：章节拆分、里程碑、交付顺序、验收标准。
- `doc/开发跟踪记录.md`：持续记录已完成、进行中、风险、下一步。

## 4. 内容质量要求

每个主题必须遵循同一讲解模板：

1. 学习目标：读完后能解决什么问题。
2. 前置知识：需要先知道 Binder、JNI、Handler、C++ 锁等哪些基础。
3. 场景故事：用车载场景说明这个模块的价值。
4. 分层调用链：从 API 到 Service/JNI/BTIF/BTA/Stack。
5. 源码导读：给出真实路径、类、方法、建议阅读顺序。
6. 简化代码片段：保留关键逻辑，附行号和通俗注释。
7. 流程图或时序图：使用 Mermaid 或 PlantUML 源码。
8. 调试方法：日志 tag、adb 命令、dumpsys 节点、snoop 观察点。


## 5. 车载重点场景

包含但不限于覆盖以下场景：

- 基础蓝牙：开关、扫描、配对、连接、取消配对、设备列表。
- 蓝牙音乐：A2DP Source/Sink、AVRCP Target/Controller、绝对音量、卡顿/无声定位。
- 蓝牙电话：HFP AG/Client、SCO 音频、通话状态、车机麦克风和扬声器通路。
- 系统设置：Settings 到 `BluetoothAdapter`/`BluetoothDevice` API 的交互，权限与 AppOps。
- 手机互联：配对触发、RFCOMM/L2CAP/BLE/GATT 可能的辅助角色、认证辅助链路。
- AIoT 外设：BLE 扫描、GATT 连接、服务发现、Characteristic 读写、Notify/Indicate、OTA 思路。
