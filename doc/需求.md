## 3. 生成内容的核心要求
### 3.1 内容覆盖面与车载重点
请围绕以下车载蓝牙典型场景进行讲解，并将每一部分与 Android 16 源码强关联：
- 蓝牙基础功能：开关蓝牙、搜索、配对、连接、取消配对、设备列表管理。
- 蓝牙音乐：A2DP Sink/Source 角色、AVRCP 控制（播放/暂停/切歌/绝对音量）。
- 蓝牙电话：HFP Client/AG 角色、通话状态同步、音频路由。
- 系统设置中的蓝牙：Settings 界面与 BluetoothAdapter/BluetoothDevice API 的交互、权限管理。
- 手机互联：HiCar、CarLink、CarPlay 等方案中蓝牙的角色（配对触发、协议通道建立、认证辅助），重点说明蓝牙在此类场景中的典型流程和协议依赖。
- 车机外接 AIoT 设备：通过 BLE 与外设（如车载香薰、空气净化器、TPMS 等）交互，涉及 GATT 连接、服务发现、数据收发。

要求：上述每个场景都必须对应到源码中的关键类、方法、状态机，并提供从 Java/Kotlin API 到 JNI，再到 Native C++ 协议栈的完整调用链路分析。

鉴于我的 C++ 基础薄弱，请做到以下几点：

- 采用“先讲是什么，再讲为什么，最后看代码”的方式。

### 3.3 学习文档结构建议（可调整，但必须包含以下核心模块）
- Android 蓝牙整体架构概览
  - 用分层架构图展示 App -> Framework -> JNI -> Native Stack -> Kernel Driver。
  - 每层核心组件及其职责（AdapterService、AdapterProperties、Device、StateMachine、HCI、L2CAP 等）。
- 开发环境与调试准备
  - 如何利用现有源码编译、烧录、抓取 HCI log / snoop log。
  - 常用 adb 命令、dumpsys bluetooth_manager、hcidump 等的使用。
- Framework 层逐模块精讲
  - BluetoothAdapter、BluetoothDevice、BluetoothProfile 的实现机制。
  - 蓝牙服务启动流程（system_server 中的 AdapterService 启动及状态机）。
  - 扫描、配对、连接的全流程源码跟踪。
- JNI 桥接层详解
  - 从 Java 调用到 Native 的映射关系，bt_jni 相关代码分析。
  - 回调如何从 Native 传递到 Java 层。
- Native 协议栈深度剖析
  - 以 Fluoride/GD 栈为例，解析 main 线程、reactor、模块初始化。
  - HCI 层、L2CAP、SDP、RFCOMM、SCO 的核心实现。
  - A2DP、AVRCP、HFP、GATT 等 Profile 的状态机、连接建立与数据传输流程。
- 车载场景专项实战
  - 蓝牙音乐卡顿、无声问题定位路径。
  - 蓝牙电话无声音、异常断连分析。
  - HiCar/CarPlay 连接过程中蓝牙配对与认证的代码级交互。
  - BLE 外设回连与 OTA 升级的流程实现。
- 附录：C++ 核心语法与常用模式速查
  - 结合蓝牙源码中出现的智能指针、Lambda、类型转换、命名空间、模板等给出实例说明。
  - 蓝牙代码中的线程同步方法（Mutex、ConditionVariable 等）实例。
